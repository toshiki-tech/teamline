# 图片下载说明

由于需要从原网站下载图片，请按以下步骤操作：

1. 访问 https://www.teamline.cn/share.html
2. 打开每篇文章的详情页
3. 右键保存文章中的图片
4. 将图片重命名并放入此目录：
   - illustration.jpg (宝藏插画分享)
   - bank-design.jpg (银行资料相关文章共用)
   - copywriting.jpg (文案相关文章)
   - thanksgiving.jpg (感恩节文章)
   - poster-design.jpg (海报设计文章)
   - creative-posters.jpg (创意海报合集)
   - design-trends.jpg (设计趋势文章)
   - typography.jpg (字体设计文章)

或者使用浏览器插件批量下载图片。

目前代码中已设置图片加载失败时显示占位符。

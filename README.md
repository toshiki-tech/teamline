# Teamline 官网现代化改版

基于 [teamline.cn](https://www.teamline.cn/) 的现代化企业官网改版方案与实现。

## 📋 项目概述

本次改版保留了原站的核心内容和导航结构，采用现代化的设计风格和技术实现，打造一个简洁、专业、响应式的企业官网。

## 🎨 设计特点

- ✅ **保留品牌配色**：延续原站顶部菜单配色方案，保持品牌连续性
- ✅ **现代企业官网风格**：简洁、大留白、专业感、设计感
- ✅ **完全响应式**：适配桌面端、平板、手机端
- ✅ **语义化 HTML**：清晰的代码结构，易于维护
- ✅ **现代 CSS**：Flexbox + Grid 布局

## 🚀 快速开始

### 本地预览

1. 直接在浏览器中打开 `index.html` 文件
2. 或使用本地服务器：

```bash

python -m http.server 8000

# 使用 Node.js (需要安装 http-server)
npx http-server

# 然后访问 http://localhost:8000
```

- 使用现代浏览器（Chrome, Firefox, Safari, Edge）

## 📐 页面结构

### 首页模块（7个核心模块）

1. **Header Navigation（固定导航栏）**
   - Logo + 主导航菜单
   - 移动端汉堡菜单
   - 固定定位，滚动时始终可见

2. **Hero Section（主视觉区域）**
   - 品牌口号："让客户期待更多 为品牌服务更久"
   - 设计公司定位："每一次 让客户多收获10%"
   - CTA 按钮

3. **Services Section（服务板块）**
   - 6项核心服务（品牌策划、视觉创意、数字营销、空间展示、交互视觉、公关策划）
   - 卡片式网格布局

4. **Featured Cases Section（案例展示）**
   - 精选项目案例
   - 大图卡片展示
   - 服务类型标签

5. **Company Advantages（公司优势）**
   - 4个核心优势点
   - 图标 + 标题 + 描述

6. **About Section（关于我们）**
   - 公司介绍文字
   - 配图展示
   - 左右分栏布局（桌面端）

7. **Footer（页脚）**
   - 快速链接
   - 联系方式
   - 版权信息

## 🛠️ 技术实现

### HTML
- 语义化标签（`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`）
- 清晰的类名结构
- 无障碍性考虑（alt 属性、aria-label）

### CSS
- **CSS 变量**：统一管理颜色、字体、间距
- **Flexbox**：一维布局（导航栏、按钮组）
- **Grid**：二维布局（服务网格、案例网格）
- **移动端优先**：基础样式针对手机，逐步增强

### JavaScript
- 导航菜单切换（移动端）
- Header 滚动效果
- 平滑滚动（锚点链接）

## 📝 设计决策说明

### 1. 配色方案
- **保留原站配色**：基于原站顶部导航栏配色，确保品牌连续性
- **主色调**：深灰色（可调整为原站实际主色）
- **强调色**：蓝色（可调整为原站实际强调色）
- **背景色**：白色 + 浅灰，营造大留白感

### 2. 字体系统
- **中文字体**：系统字体栈（苹方、微软雅黑、思源黑体）
- **字体大小**：响应式缩放，使用 CSS 变量统一管理
- **字体层级**：清晰的标题层级（H1-H3）

### 3. 间距系统
- **8px 基准**：8px, 16px, 24px, 32px, 48px, 64px, 96px
- **响应式间距**：桌面端大间距，移动端紧凑间距
- **使用 rem 单位**：基于根字体大小，易于缩放

### 4. 布局策略
- **Grid 布局**：服务、案例、优势等模块使用 Grid
- **Flexbox 布局**：导航栏、按钮组等使用 Flexbox
- **双列布局**：关于我们区域桌面端左右分栏

### 5. 交互设计
- **悬停效果**：卡片上浮、阴影加深
- **过渡动画**：0.3s ease 统一过渡
- **移动端适配**：汉堡菜单、触摸友好

## 📱 响应式适配思路

详细的响应式设计思路请查看 [响应式适配说明.md](./响应式适配说明.md)

**核心策略：**
1. 移动端优先设计
2. 使用 Flexbox + Grid 实现灵活布局
3. CSS 变量统一管理，易于调整
4. 相对单位（rem, %, vw）实现响应式缩放
5. 媒体查询针对不同断点优化
